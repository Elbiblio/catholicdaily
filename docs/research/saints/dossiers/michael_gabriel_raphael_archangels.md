# Saints Michael, Gabriel, and Raphael, Archangels

## Identity resolution

- Stable ID: `michael_gabriel_raphael_archangels`
- Profile kind: Angelic
- Celebration IDs: `michael_gabriel_raphael_archangels`, `saints_michael_gabriel_and_raphael_archangels`
- Canonical name and aliases: Saints Michael, Gabriel, and Raphael, Archangels; the Holy Archangels
- Feast date and calendar scope: September 29; universal Roman feast
